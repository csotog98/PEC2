## Resumen de las técnicas

### 1. Pie Chart
Muestra la distribución de las ventas por región. Funciona bien porque solo hay 4 regiones y se ve rápido cuál vende más.

### 2. Sunburst Chart
Muestra los datos organizados por niveles: Región, Categoría y Subcategoría. Sirve para ver cómo se dividen las ventas dentro de cada zona.

### 3. Marimekko Chart
Relaciona el segmento de cliente con la categoría de producto. El ancho de la barra representa el total de ventas del segmento y la altura el porcentaje de cada producto.
